# Terminal reference library

Read [`index.md`](index.md) first. It is the authoritative English catalogue
for SuperTerm's internal terminal core, host-terminal handling, platform
backends, product profiles and official upstream sources.

Local files are retained only when their redistribution terms permit it and
their source/version can be recorded. An official link in the index is used
when a publisher provides no redistributable technical manual. `SHA256SUMS`
records the exact bytes in this directory.

Do not infer implemented support from the presence of a manual. A capability
may be advertised only after its production implementation and end-to-end
conformance tests pass.
